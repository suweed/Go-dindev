--------------------------------------------------------------------------------------------------------

	- historia (lore)
		- es el primer día de trabajo en un nuevo empleo
			- fue despedido de su trabajo anterior
			- andaba buscando otro trabajo antes de terminar con sus ahorros
			- logra encontrar este nuevo trabajo justo a tiempo
		- solo tiene 10,000 de dinero (ahorros) para administrar y llegar a fin de mes
			- los 30 días del proyecto son el mes
			- el dinero es fijo al inicio y va disminuyendo
			- debe administrarse para no terminarlo antes del mes
				- comprar comida
				- comprar ropa
				- otros ítems
				- transporte
		- el objetivo del juego es terminar el proyecto
			- sin quedarse sin dinero
			- sin morir de cansancio
		- el dinero puede aumentar recibiendo bonos
			- por resolver alguna actividad de trabajo rápido
			- por descubrir algún secreto
			- los bonos y secretos se establecen después
		- el MVP es el flujo principal de la historia
			- los finales se establecen después (habrá varios)
		- a futuro (no en esta versión): al terminar el mes se cobra el salario y se pagan renta y gastos de la casa

	- apariencia
		- juego de tiipo click and point, puzzle, accion, triller, investigación
		- perspectiva de cámara isométrica
		- personaje y ubicaciones en 3D
		- efecto de grabación tilt-shift
	
	-  tecnología
		- react three fiber
		- threejs
		- poder abrirlo en mobile y desktop

			- cumplir con el objetivo/proyecto en 30 días (30 min)(configurable)(happy path)
				- pensar en el proyecto o los proyectos disponibles
			- ser despedido
				- llegar a los 30 días y no terminar el proyecto
			- encontrar algún final
		- definir rutina de personaje inicia oficina
			- cada sesión es de 30 días por proyecto
				- el proyecto se asigna aleatorio
					- definir varios proyectos
					- los proyectos son la meta final del proyecto
						- cumplir los 30 días finaliza el juego
							- el proyecto se cumple con las actividades de trabajo
								- minijuegos
				- cada día se deben cumplir con las actividades de trabajo
					- cada actividad acumula porcentaje de proyecto final
				- el día termina cuando se cumple el tiempo diario o se terminan las actividades

------------------------------------------------------------------------------------------------------------

cansancio

	- el cansancio se incrementa dependiendo de las actividades, el cansancio tiene un gasto fijo igual que el tiempo
	  cada día tiene un incremento por default
	- el cansancio puede provocar pantallas de decisiones
	- si no se maneja el cansancio y se llena genera un final de muerte por cansancio
		- se vuelve loco
		- se muere y se va un isekai
		- se va a una montaña de ermitaño
	- el cansancio se puede disminuir con ítems
		- comida y bebida
		- ropa

tutorial

	- vamos a generar el tutorial para aprender las mecánicas de tiempo, cansancio, actividades y decisiones
	- el tutorial se desarrolla en la habitación inicial
	- el tutorial no cuenta como tiempo para el proyecto se desarrolla una noche antes del primer dia de trabajo
	- el tutorial puede afectar al primer día


	- acepta empezar en pantalla de bienvenida
	- primera partida
		- muestra animación de noche anterior a primer día
			- preparar cosas para el primer día
		- en la pantalla de al animación muestra las opciones
			- continuar con el tutorial
				- si incia el juego en la habitación
				- el personaje se levanta de la cama 
				- se presentan objetivos del tutorial
					- preparar comida y bebida
						- 1 iitem de cada uno
					- preparar ropa de oficina
					- contar dinero 
				- se presentan los botones de dirección para caminar
				- se activa el primer dialogo
					- da la bienvenida al tutorial y se explica que estamos en la noche anterior al primer día
					- explica que se debe preparar las cosas para el día siguiente
						- comida
						- bebida
						- ropa
					- debe moverse el personaje al minibar
						- señalar minibar para que el personaje camine
						- el personaje al llegar se presenta la mecánica de activar una acciona en algún objeto
							- se abre el minibar y muestra menú de ítem en el anterior para obtener y prepararlos para el siguiente día
						- guarda una bebida y una comida y se activa objetivo de preparar comida
					- al terminar el minibar se prepara ropa
						- se señala el ropero
						- el personaje se acerca y se activa la accion de abrir ropero
						- sale menú de ropero, menciona que se puede tener diferentes ropas comprándolas y que se debe preparar la ropa de oficina
							- solo se tiene la ropa de oficina al principio
						- se obtiene la ropa de oficina, se guarda y se activa objetivo de preparar ropa
							- no se cambia la ropa actual que es la ropa de casa
					- al terminar la ropa se señala la cama
						- se acerca y se activa la opción para dormir
							- se muestra dialogo para explicar la mecánica de dinero y cansancio
								- presenta la mecánica del dinero
									- informa que hay gastos por default como el transporte
									- informa que se pueden comprar ítems y ropa
								- presenta la mecánica del cansancio
									- informa que hay cansancio por default como el trabajo pero se recupera un poco durmiendo o con ítems
					- al terminar dialogo final se activa pantalla de despertar
			- saltar tutorial
				- continua con pantalla de despertar
